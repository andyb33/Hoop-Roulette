# Hoopreel v0.11.1

Usability update for the complete 46-season pool (1980–81 through 2025–26): 12,169 entries. Normal spins take 1.1 seconds; rerolls at most 0.73 seconds, with kept reels skipped and reduced-motion preferences respected. Year lands before Team, then Player; all preview names come from eligible candidates for that result.

The finished popup offers View scorecard and Play Again. Escape also dismisses it. Scores in the header opens the last 50 completed scorecards, with personal best retained independently. History is saved in the current browser on this device; private browsing, changing the launcher port/browser, or clearing site data can affect availability. Jackpot development previews are excluded. If storage is unavailable, gameplay continues and scores remain available for the current page session.

New games use Batch 25. Extract the complete Windows or Mac artifact archive and run the launcher. Mac artifacts include an inner ZIP containing the app and instructions. These are unsigned alpha packages. Source users can run `python scripts/run_web.py`.

Desktop build status and download links are recorded after the corresponding Actions jobs pass.
