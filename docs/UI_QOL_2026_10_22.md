# UI quality-of-life update — 2026-10-22

The source UI now includes five faster-play and recovery controls:

- **Skip animation:** appears during a reveal and lands the same spin result immediately. It never requests another spin.
- **Instant spins:** bypasses reel animation and jackpot particles. The checkbox is remembered in this browser when storage is available; otherwise it works for the current session. Reduced-motion preferences remain respected.
- **New game warning:** an unfinished game with a spin or scored category requires confirmation before replacement. Keep playing or Escape cancels. Fresh and completed games start again directly.
- **Bonus tracker:** shows the points remaining to reach the 120-point upper threshold, then confirms that the bonus was earned.
- **Clear Keeps:** releases the selected keeps together without spinning. Disabled when no keeps can be cleared or an action is in progress.

Validation: 142 Python tests, frontend behavior checks, JavaScript syntax and diff checks passed. Frontend coverage includes skipping each reel, jackpot reveals, repeat clicks, late timer cleanup, instant preference persistence and unavailable storage, restart confirmation paths, bonus text and clearing keeps during busy state.

These are source changes on top of v0.12.0. The 53-season pool and scoring rules are unchanged. Existing desktop archives do not include this update; desktop packaging and visual browser/mobile QA have not been rerun for it. Public hosting remains pending.
