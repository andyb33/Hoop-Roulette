# Hoopreel v0.12.1 — desktop alpha

Spin. Keep. Score.

## Windows

Fully extract the downloaded archive, then open `Hoopreel-v0.12.1-Alpha.exe`. The launcher opens the game in your default browser. Keep the launcher running while playing; close its console when finished. Python is not required.

## Mac — Apple Silicon only

This build is for Macs with Apple M-series chips (M1 or later). Intel Macs are no longer included in new builds. Check Apple menu → About This Mac → Chip.

Extract the artifact archive, then its inner ZIP, and open `Hoopreel-v0.12.1-Alpha.app`. The app opens the game in your default browser. Python is not required. The alpha is not Developer ID signed or notarized; macOS may require approval through Privacy & Security to open it. Quit the launcher when finished.

## What's new

- Skip animation reveals the same result immediately without another spin.
- Instant spins bypasses animation; its setting is remembered in this browser when storage is available.
- Starting a new game warns before replacing an unfinished game.
- The upper bonus tracker shows how many points remain to reach 120, then confirms the +35 bonus.
- Clear Keeps releases every selected keep without spinning.

The normal pool remains 53 seasons, 1973–74 through 2025–26, with 13,442 entries. New games use Playtest Batch 27. Rules and eligibility remain unchanged.

Completed scores and the personal best are saved in this browser on this device. Changing the launcher address/port or clearing browser data can affect history availability. In-progress games require the launcher to remain running. Development previews are excluded from saved score history and playtest logging.
