# Hoop Roulette v0.15.0 — desktop polish

Windows: extract the ZIP, run HoopRoulette-v0.15.0-Setup.exe, then open Hoop Roulette from Start. Mac: extract the inner ZIP and open the Apple Silicon app (M1 or later).

The header shows your saved personal best; the footer shows the normal 53-season range, 1973–74 through 2025–26, with earlier legends available separately as Prehistoric Jackpots. Keep exactly Team + Player and open Reroll possibilities to inspect other legal seasons and scores in unused categories. One season is shown per page. If no alternative exists, the preview explicitly says the result repeats. Previewing does not spend a spin or select the next outcome.

Sound starts off. Use Sound on in the header to enable original synthesized reel, Keep, scoring, jackpot and record cues. The preference is remembered. New records receive a gold highlight and scoring gets a brief flash; reduced-motion settings are respected.

Scores → Clear history asks for confirmation, then removes saved scorecards and personal best on this device. Current game, sound/Instant spins settings and playtest log files remain. This action cannot be undone through the app. Existing saves remain compatible. New completed games use Batch 31, separate from the 19 reviewed Batch 30 games.

Data, scoring and eligibility are unchanged. No account, Python or command prompt is needed. Gameplay works offline; Windows requires WebView2 Runtime. Builds remain unsigned; Mac is not notarized.
